# Installation

## Stable release

To install x-series, run this command in your terminal:

```sh
uv add x-series
```

Or if you prefer to use `pip`:

```sh
pip install x-series
```

## From source

The source files for x-series can be downloaded from the [Github repo](https://github.com/mlotfic/x_series).

You can either clone the public repository:

```sh
git clone git://github.com/mlotfic/x_series
```

Or download the [tarball](https://github.com/mlotfic/x_series/tarball/master):

```sh
curl -OJL https://github.com/mlotfic/x_series/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd x_series
uv pip install .
```
